# 중소기업 청년 소득세 감면 계산기 (2026년 귀속)

연봉과 비과세 항목만 넣으면, 2026년 귀속 연말정산 기준으로 **중소기업 취업자 소득세 감면(청년 90%, 연 200만 원 한도)** 까지 반영한 예상 소득세를 계산합니다.

- 라이브: https://lb4580708-wq.github.io/youth-tax-calculator/
- 만든 사람: 김쿼카의 이것저것

## 계산에 반영한 것

| 단계 | 근거 |
| --- | --- |
| 비과세 소득 | 식대 월 20만 · 자가운전보조금 월 20만 · 출산·보육수당 자녀 1명당 월 20만 · 기타 |
| 근로소득공제 | 소득세법 제47조 (70% / 40% / 15% / 5% / 2%, 한도 2,000만 원) |
| 4대보험료 소득공제 | 2026년 근로자 부담 9.7174% (국민연금 4.75 · 건강 3.595 · 장기요양 건보료의 13.14 · 고용 0.9) — 끌 수 있음 |
| 기본공제 | 본인 150만 원 |
| 세율 | 6~45% (과세표준 1,400만 · 5,000만 · 8,800만 · 1.5억 · 3억 · 5억 · 10억 원) |
| 근로소득세액공제 | 소득세법 제59조 (55% / 71.5만 + 30%, 총급여별 한도 74만~20만 원) |
| 표준세액공제 | 13만 원 |
| 중소기업 취업자 감면 | 조세특례제한법 제30조 · 시행령 제27조 — 산출세액 × 90%(70%), 연 200만 원 한도, 감면 시 근로소득세액공제도 감면 비율만큼 조정 |
| 지방소득세 | 결정세액의 10% |

## 반영하지 않은 것

카드·의료비·월세·보험료 세액공제, 부양가족·배우자 공제, 연금계좌 세액공제, 중도 입사·이직한 해의 감면 대상 급여 비율.
